discord-mcp 管理

ログイン

AI ごとにコネクタの URL を発行します。URL をその AI (claude.ai のカスタムコネクタなど) に登録すると、投稿はここで決めた名前の webhook (またはボット自身の名前) で行われます。

Discord のボットごとの設定です。1 つのボットで、招待したサーバー全部を扱えます。保存すると accounts/<名前>.toml を書きます。トークンは画面に表示しません。

ボットの作り方

  1. Discord Developer Portal で New Application を作ります (名前がボットの表示名になります)。
  2. 左の Bot で Reset Token を押し、出たトークンを「ボットとサーバー」タブで登録します (トークンは一度しか表示されません)。
  3. 同じページの Privileged Gateway Intents で Message Content Intent をオンにします (オフだと、ボット宛てでないメッセージの本文が読めず、本文の検索もできません)。メンバーの一覧を使うなら Server Members Intent もオンにします。
  4. ほかの人にボットを入れさせないなら、Public Bot をオフにします。
  5. 「ボットとサーバー」タブの 招待 から、ボットを入れるサーバーを選んで認証します (そのサーバーの「サーバー管理」の権限が要ります。管理者でないサーバーは、招待 URL を管理者に渡して入れてもらいます)。
  6. 非公開のチャンネルは、そのチャンネルの権限でボット (かボットのロール) に「チャンネルを見る」「メッセージ履歴を読む」を許可します。
招待 URL に含める権限

    「ウェブフックの管理」は、AI の名前で投稿する (投稿方法が webhook の AI) ために使います。すべての AI をボットの名前で投稿させるなら、なくても動きます。
